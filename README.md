# Familienabend / أمسية عائلية

Fünf vollständig zweisprachige Spiele: Imposter, Scharade, Tabu, Familienquiz und Wer bin ich?

خمس ألعاب باللغتين الألمانية والعربية: المحتال، التمثيل الصامت، الكلمات الممنوعة، مسابقة العائلة، ومن أنا؟

Dieses Repository enthält alle Spiele, damit sie auch ohne separate Pages-Freischaltung der Einzelspiele funktionieren. Jedes Spiel hat außerdem ein eigenes Repository. Änderungen werden als getestete Kopien in der Sammlung übernommen.

GitHub Pages: Settings → Pages → Deploy from a branch → main → /(root) → Save.

https://norobbc-wq.github.io/familienabend/

## Inhalte

- Imposter: 273 zweisprachige Wortpaare und eigenes Wort
- Scharade: 200 zweisprachige Aktionen
- Tabu: 150 Karten mit je 3 verbotenen Wortpaaren
- Quiz: 160 Fragen mit je 4 zweisprachigen Antworten
- Wer bin ich?: 273 zweisprachige Karten

Zufällige Inhalte werden pro Spiel ohne Wiederholung ausgewählt. Der Verlauf bleibt im Browser gespeichert, auch nach Neuladen. Neuer Spieleabend setzt den Verlauf aller Spiele zurück. Bei ausgeschaltetem Browserspeicher gilt die Sperre nur bis zum Neuladen.

Statisch, ohne externe Bibliotheken, ohne Speicherung oder Übermittlung von Spielernamen.
